# PC МАСТЕР Mobile

Облегчённая версия для телефонов. Правила игры те же, что и на ПК.

Что убрано ради скорости: тени, отражения, обводки аниме-стиля, зерно и затемнение, паркет с рельефом, лучи, админ-консоль, антиалиасинг. Осталось меньше ламп, ближе туман, плотность пикселей 1.25 (дальше сама снижается, если FPS падает).

## Как запустить на телефоне
1. Залей ВСЕ файлы из этой папки в отдельный репозиторий GitHub (например `pcmaster-mobile`).
2. Settings → Pages → Branch: main, папка root. Через минуту сайт откроется по ссылке `https://ТВОЙ_НИК.github.io/pcmaster-mobile/`.
3. Открой ссылку в Chrome на телефоне, меню ⋮ → «Добавить на главный экран». Игра запустится как приложение на весь экран.

Файла `three.min.js` в папке нет: игра берёт three.js из интернета (cdnjs). Хочешь без интернета: положи `three.min.js` версии r128 рядом с `index.html`.

## Приложение для Android (.apk)
1. В репозитории нажми Add file → Create new file. В поле имени напиши `.github/workflows/build.yml` и вставь туда содержимое файла `build.yml` из этой папки. Commit.
2. Вкладка Actions → «Build Android APK» → Run workflow. Через 5–8 минут внизу страницы запуска появится артефакт `PC-MASTER-Android`.
3. Скачай, распакуй, перекинь `app-debug.apk` на телефон и установи (Android попросит разрешить установку из неизвестных источников).

## iPhone
Файл .ipa без аккаунта разработчика Apple поставить нельзя, поэтому на iPhone игра ставится как веб-приложение: открой ссылку GitHub Pages в Safari → «Поделиться» → «На экран Домой».

## Управление
Левая часть экрана: стик движения. Правая: поворот камеры. Кнопка «Действие» или касание предмета: взять и использовать.
